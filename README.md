# 🎓 College Complaint Portal

> A modern and responsive web-based complaint management system designed to help college students submit, track, and manage campus-related complaints efficiently.


## 📌 About the Project

The **College Complaint Portal** is a frontend web application designed to provide students with a simple and organized way to report problems or issues within their college campus.

Students can submit complaints, select categories and priorities, track complaint statuses, search previous complaints, and view complaint details through a clean dashboard interface.

The project uses **HTML, CSS, and JavaScript**, with **Browser LocalStorage** for storing complaint data.

---

## ✨ Features

### 👨‍🎓 Student Dashboard

* 📊 Complaint statistics
* 📋 Recent complaints
* ⏳ Pending complaints
* 🔄 In-progress complaints
* ✅ Resolved complaints

### 📝 Complaint Management

* Submit new complaints
* Automatically generated complaint IDs
* Select complaint category
* Set complaint priority
* Add location and description
* Select complaint date
* View complete complaint details
* Delete complaints

### 🔍 Search & Filter

* Search complaints by:

  * Complaint ID
  * Subject
  * Category
* Filter complaints by status
* View complaints in a structured table

### 💾 Data Storage

Complaint information is stored using **Browser LocalStorage**, allowing data to remain available after refreshing the page.

### 📱 Responsive Design

The interface is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet
